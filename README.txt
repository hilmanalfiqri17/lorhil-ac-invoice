AC SERVICE MANAGEMENT — DEMO V2 (TAMPILAN MIRIP PRODUK ASLI)

Versi ini dibuat dari struktur tampilan produk asli, tetapi:
- Tidak menggunakan nama toko asli.
- Semua pelanggan, teknisi, invoice, pendapatan, dan jadwal adalah data fiktif.
- Tidak terhubung ke Supabase.
- Tidak mengirim WhatsApp sungguhan.
- Data perubahan hanya disimpan di localStorage browser.
- Bisa di-reset dari tombol Reset Demo.

CARA UPLOAD KE GITHUB PAGES
1. Buat repository baru, contoh: ac-service-management-demo
2. Upload SEMUA isi folder ini ke root repository.
3. GitHub -> Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /root.
6. Save.
7. Tunggu deployment selesai.

Catatan:
Jangan digabungkan dengan repository sistem usaha asli. Demo sebaiknya memiliki repository/domain terpisah.
